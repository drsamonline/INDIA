# Security policy

## Scope

This repository is a static website: HTML, CSS, ES modules, vendored three.js
and image files. It has no server, no database, no accounts and no user input
that is stored or transmitted. The attack surface is therefore small, but not
zero — a malicious dependency, a tampered asset, or script injection through
generated HTML would still matter.

## Reporting a vulnerability

Email **sohilmomin2000@gmail.com** with:

- what you found and where (file, page URL, commit),
- how to reproduce it,
- the impact you believe it has.

Please do not open a public issue for a live vulnerability. You can expect an
acknowledgement within 7 days and a fix or an explanation within 30.

## Supported versions

Only the `main` branch is supported. There are no releases; the site is served
from the branch tip.

## What is in scope

- Script injection through `data/monuments.json` into the generated pages
  (the build escapes values, but a bypass would be a real finding).
- A compromised or unexpected file in `assets/vendor/` or `assets/fonts/`.
- A photograph used beyond its licence, or a missing attribution.
- Any way to make a page execute third-party code.

## What is out of scope

- Denial of service against a static host.
- Missing security headers on GitHub Pages, which we do not control.
- Reports generated by an automated scanner with no demonstrated impact.
